# 3D Developer Portfolio - Gunasri A

A modern, interactive **3D Developer Portfolio Website** for **Gunasri A**, built with Three.js, HTML5, CSS3, JavaScript, and custom 3D canvas experiences.

![Tech Stack](https://img.shields.io/badge/Stack-Three.js%20%7C%20HTML5%20%7C%20CSS3%20%7C%20JS-00cea8?style=for-the-badge)

## 🌟 Key Features

- **3D Hero Workstation**: Interactive Three.js developer laptop scene with code display textures, dynamic lighting, and float animations.
- **Background Starfield Canvas**: Animated particle canvas background.
- **3D Tech Skill Spheres**: Floating interactive technology spheres for Python, Java, HTML5, CSS3, JavaScript, React.js, Node.js, MySQL, MongoDB, Git, OCI.
- **3D Earth Globe Canvas**: Rotating wireframe 3D sphere with glowing core and orbit ring in the Contact section.
- **Academic & Experience Highlights**:
  - B.E. Computer Science & Engineering (IFET College of Engineering, CGPA: **8.47**)
  - Intern @ Aaha Solution (*Time and Attendance Management System*)
  - Project: *Wrong Posture Muscular Strain Detection*
  - Verified Certifications & Interpersonal Soft Skills
- **Interactive Features**: Smooth scrolling navigation, mobile menu toggle, interactive contact form, and direct PDF resume download.

## 📁 Repository Structure

```text
├── index.html            # Main HTML document
├── css/
│   └── style.css         # Custom design tokens, glassmorphic cards, responsive styling
├── js/
│   ├── three-scene.js    # Three.js 3D workstation, starfield & earth globe scripts
│   └── main.js           # Scroll handlers, mobile menu, form handling & resume download
└── Gunasri_A_Resume.pdf  # Factual PDF resume download asset
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/gunasrikumar159-cloud/portfolio.git
   ```
2. Open `index.html` in any modern web browser or serve via HTTP:
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000`.
